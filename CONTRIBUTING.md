# Contributing to ANS Parser

Thanks for contributing! This guide explains how to contribute to the ANS Parser for ApexRegistry.

## How to contribute
1. Fork this repository.
2. Create a branch: `git checkout -b feat/your-feature-name`.
3. Make your changes and add tests if applicable.
4. Run tests: `pytest`.
5. Open a Pull Request (PR) with a clear description of your changes.

## Code style
- Use clear, simple Python 3.9+ code.
- Keep functions small and focused.
- Add docstrings to public functions.
- Prefer readability over cleverness.

## Testing
- Add tests in `tests/` for new behavior.
- Make sure all tests pass before opening a PR.
